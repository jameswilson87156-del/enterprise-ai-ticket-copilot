- v3 报告留下的边界风险得到复现：旧清理规则在“攻击前缀；真实症状”样本上 5/5 未保留类别信号。

- 最终逻辑只在分号后以“Actual issue:”或“实际问题：”开头、且尾段没有命中已识别注入模式时保留后段；其他同句混合内容仍按原句移除。
- 新增 `sync`、`duplicate` 英文数据类信号，使英文重复同步问题可以进入数据问题分类；现有标签没有更改。
- 修复后的单测直接断言清理结果仍包含真实问题段，并同时回归旧恶意指令链。

## 仍然存在的边界

清理器是窄范围的词面启发式。它只在上述明确标记条件下保留分号后的文本；未标记的同句混合指令与症状仍可能一起被删除。规则分类 60/60 不能证明 LLM 能抵御提示注入。真实 DeepSeek 红队请求仍待轮换已暴露的旧密钥、配置新的本机密钥后再按受控批次运行。
