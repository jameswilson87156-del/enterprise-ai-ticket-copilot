# FRONTEND_CRAFT — 专业支持工作台精修

日期：2026-09-05  
任务范围：现有 Vue 前端的视觉层次、工作台布局与交互精修。不变更后端 API、认证、工作流状态机和真实 Provider。

## 1. 这轮解决什么

原界面的问题不是缺少装饰，而是所有内容处在同一视觉优先级：队列、详情、AI 建议、创建表单、完整证据和历史全部展开。右栏重复嵌套卡片，主工作区高度失衡，侧栏说明多于操作。

本轮定位为“支持人员每天使用的专业工作台”，不走营销页、科技大屏或泛用 AI 仪表盘方向。主要阅读顺序：选择工单 → 阅读问题 → 运行建议 → 核对证据 → 人工决策。审计信息保留，但不抢占默认首屏。

## 2. 参考案例与取舍

| 官方参考 | 采用的设计方法 | 在本项目的落点 | 不照搬的内容 |
| --- | --- | --- | --- |
| [Linear UI redesign](https://linear.app/now/how-we-redesigned-the-linear-ui) | 降低导航噪音，保持面板边缘和文字基线对齐 | 紧凑侧栏、统一工作区边框、选中行、不重复显示导航副标题 | 品牌标识、营销素材、项目管理业务 |
| [Intercom Inbox](https://www.intercom.com/helpdesk/inbox) | 把处理对象、上下文与辅助信息放在相邻区域 | 左队列 / 中详情 / 右处理建议，内容分区而不是卡片套卡片 | 客服全渠道、未实现的团队协作和自动化功能 |

研究用官方页面确定结构方法；代码与文案为本项目自己的实现。不是下载或复制其商业前端。

## 3. 视觉规范

- 画布：#FAFBFC；侧栏：#F2F4F6；内容：白色。
- 主文字：#202830；辅助文字：#52606E；边线：#E3E7EB。
- 主动作：#3654A4；选中项使用浅靛色背景与左侧标记。
- 大标题 27px；详情标题 21px；正文 13px；控件 12px；技术元数据使用较小等宽字体。
- 面板圆角 8–9px，控件 6px，不使用多层阴影或渐变装饰。
- 侧栏桌面宽度 208px；工作台三栏为 250px / 自适应 / 320px。
- 普通状态、风险、成功、失败继续保留不同语义色，不因为统一主题而让危险操作失去辨识度。

## 4. 结构与交互

1. 新建入口放在页头，使用原生 dialog 打开合成工单表单；具备对话框标题、关闭按钮、Escape 关闭和浏览器原生焦点约束。
2. 创建默认样例改为中文合成内容，不预填任何真实用户或密钥。
3. 取消默认预填“已经审查证据”的审核备注；批准的空备注只记录“审核通过”，要求修改与驳回仍要求原因。
4. 默认工作区保留队列、详情、建议、风险和审核。
5. 完整结构化结果、引用和历史放入可展开的“完整证据与审核记录”；右栏“查看全部”可展开并定位。
6. 1280px 以上三栏各自滚动，避免某一栏无限撑高。760–1279px 为队列与详情两栏，处理建议在下一行。手机单列并保留步骤导航，队列限制高度。
7. Demo/后端 API、Provider 和安全拒答标记保持可见；没有增加静默 Mock 回填。

## 5. 实现约定

- 主要交互：frontend/src/views/TicketWorkbenchShowcaseView.vue。
- 主题入口：frontend/src/main.ts 在 styles.css 后导入 craft.css。
- 精修规则集中在 frontend/src/craft.css；工作台规则使用 .workbench-page 限定。
- 原有 styles.css 含历史设计规则。本轮保留，避免覆盖用户其他页面的未提交修改；后续统一样式时应逐项迁移后删除旧规则，不继续叠加第四套主题。
- 不新增生产依赖、外部字体或远程图片。

## 6. 验收方法

构建：在 frontend 执行 npm run build，包含 vue-tsc。  
跨项目浏览器脚本：D:/workhome/frontend-craft-qa.cjs。  
截图目录：D:/workhome/frontend-craft-20260905。

验收要求：
- 桌面和手机无横向溢出、无运行时异常、无破图。
- 创建弹窗能打开、Escape 关闭并恢复触发按钮焦点。
- 本地 Demo 创建 → Copilot → 批准 → 审核历史可完整执行。
- 其他六个工单页面回归检查，不能只检查工作台首页。
- 数据不足、未运行或不满足复核门禁时，不用视觉设计伪装成成功状态。

本轮前端视觉验收不等于真实认证、真实 MySQL、真实 Provider 或公网部署验收。后者沿用独立的发布门禁。
